# 线性表上机

源文件保留 `.cpp` 后缀，代码采用 C 写法。员工记录是线性表的元素 `ElemType`。顺序表 `SqList` 用 `elem`、`length`、`listsize` 保存数组、表长和容量，初始容量为 80，每次扩容增加 10，并用循环复制原有元素。单链表用 `LNode` 表示结点，`LinkList` 记录头指针、尾指针和表长。

第一题的完整程序在 `顺序表.cpp`，第二题在 `单链表.cpp`。每份程序都有自己的 `main()` 和员工管理菜单，可以单独编译。运行后直接录入初始员工。原有多文件目标 `employee_manager` 启动时可以选择存储方式。

## 编译和运行

在 `线性表上机` 目录（包含 `CMakeLists.txt`）中运行以下命令。

```sh
cmake -S . -B build
cmake --build build
./build/employee_sequential  # 第一题
./build/employee_linked      # 第二题
```

使用 CLion 时，选择 `employee_sequential` 或 `employee_linked` 目标运行。

## 交互流程

1. 输入初始员工人数 `n`，按提示逐项录入每位员工的姓名、职务和工号。初始人数可以为零。
2. 输入操作次数 `m`，也可以直接回车，继续操作直至主动退出。
3. 每次选中一项后，按提示录入所需信息，再查看结果。

| 菜单选项 | 操作 | 说明 |
| --- | --- | --- |
| `1` | 员工入职 | 逐项输入员工信息，通过工号查重后添加到表尾 |
| `2` | 员工离职 | 输入工号，有对应员工时删除并提示结果 |
| `3` | 查询员工 | 输入工号，查看匹配员工的信息 |
| `4` | 查看员工名单 | 按当前顺序输出全部在职员工 |
| `0` | 退出 | 输出最终名单并结束程序 |

工号按字符串处理，会保留前导零。选择固定次数时，入职、离职和查询每办理一次计一次，查看名单可随时使用。达到 `m` 次后，程序打印最终名单并退出。输入 `m = 0` 时，程序直接打印初始名单。

姓名和工号每行最多输入 63 字节，职务最多输入 127 字节。超过长度时，程序会提示重新输入。两个独立程序会保留字段中的首尾空格，输入工号时请与录入时保持一致。UTF-8 中文字符通常占 3 字节。

## 与课件对应的接口

类型和接口参照第二章课件 2.1、2.2 和 2.3 节。顺序表函数用 `_Sq` 后缀，单链表函数用 `_L` 后缀。修改表或返回元素时，C 写法通过指针传参。

| 接口 | 约定 |
| --- | --- |
| `InitList`、`DestroyList` | 建立空表、销毁表 |
| `GetElem` | 通过输出参数取得第 `i` 个元素 |
| `LocateElem` | 逐个比较工号，返回从 1 开始的位序。找不到时返回 0 |
| `ListInsert` | 在第 `i` 个元素前插入，`i = 表长 + 1` 时尾插 |
| `ListDelete` | 删除第 `i` 个元素，并通过输出参数返回它 |
| `ListTraverse` | 逐个调用 `PrintEmployee` 打印员工记录 |

## 文件与复杂度

| 文件 | 用途 |
| --- | --- |
| `顺序表.cpp` | 第一题的独立完整程序 |
| `单链表.cpp` | 第二题的独立完整程序 |
| `main.cpp` | 程序入口、终端菜单、输入校验和员工管理函数 |
| `include/employee.h`、`src/employee.cpp` | 员工结构及记录输出 |
| `include/sequential_list.h`、`src/sequential_list.cpp` | 顺序表的扩容、插入、删除、查找、访问和输出 |
| `include/linked_list.h`、`src/linked_list.cpp` | 单链表的插入、删除、查找、访问和输出 |

设当前员工数为 `k`，两种表按工号查找和遍历输出均为 `O(k)`。顺序表按位序取元素为 `O(1)`，尾插在容量足够时为 `O(1)`，扩容或中间搬移元素最坏为 `O(k)`。单链表尾插为 `O(1)`，任意位置的插入、删除和按位序取元素最坏为 `O(k)`，其中定位结点需要遍历。两种程序的入职、离职、查询都先按工号查找，因此每次操作最坏为 `O(k)`。
